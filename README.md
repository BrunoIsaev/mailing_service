# Сервис рассылок (mailing_service)

Учебный проект на Django — платформа для управления email-рассылками.

## Функционал

**Часть 1:**
- Управление клиентами (создание, просмотр, изменение, удаление)
- Управление сообщениями рассылки
- Управление рассылками с автоматическим пересчётом статуса (создана / запущена / завершена)
- Отправка рассылок по требованию с фиксацией попыток (успешно / неуспешно, ответ сервера)
- Главная страница со статистикой (всего рассылок, активных, уникальных получателей)
- Админ-панель для всех моделей

**Часть 2:**
- Регистрация с подтверждением email (письмо со ссылкой)
- Вход, выход, восстановление пароля по email
- Роли: пользователь и менеджер (группа «Менеджер»)
- Пользователь управляет только своими клиентами, сообщениями и рассылками
- Менеджер просматривает все данные, список пользователей, блокирует пользователей и отключает рассылки
- Страница статистики: успешные и неуспешные попытки, количество рассылок
- Серверное кеширование (low-level cache) и клиентское кеширование (Cache-Control)

## Стек

- Python 3.14, Django 6.1
- SQLite
- HTML/CSS (шаблоны Django)

## Запуск


Открыть http://127.0.0.1:8000/

## Тестовые роли

- Менеджер: создать суперпользователя и добавить его в группу «Менеджер» через админ-панель
- Обычный пользователь: зарегистрироваться на сайте и подтвердить email по ссылке из письма (письма выводятся в консоль)
